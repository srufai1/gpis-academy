# Mockups

Five screens as plain-text wireframes. Phone first: each frame is 360px wide (about 40
characters). On a computer the same content sits in a centred column with a left sidebar.

| File | Screen |
| :--- | :--- |
| `01-landing.md` | Landing page (signed out) |
| `02-course-map.md` | Course map (home after sign-in) |
| `03-lesson.md` | Lesson with its quiz |
| `04-project-task.md` | Project task and checker result |
| `05-progress.md` | Progress |

Rules for every screen: one main button, touch targets at least 44px, no text that repeats a
label, the bottom bar has three places (Map · Progress · Me).

Legend: `[ Button ]` main button · `( Button )` quiet button · `>` opens · `✓` done ·
`●` current · `○` not started · `✗` failed.
